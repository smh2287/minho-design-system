# 의미 토큰

**승인된 값은 없다.**

- `provisional.css` — 잠정 토큰. 상태: 실험. 문서 사이트가 이 파일을 직접 읽는다.
  역할 이름(바탕·표면·본문 글자·보조 글자·경계·강한 경계·hover·포커스 / 글자 5역할 / 간격 8단계)은 유지하고 값만 시험한다.
- 강조색·오류·성공 역할은 아직 없다. 그 의미를 가진 화면과 결정(사이트 `/decisions/` 질문 2)이 먼저다.
- Fable 실험안 v3의 CSS 변수를 그대로 표준으로 승격하지 않는다.
- 값이 승인되면 `provisional.css`에서 별도 파일로 옮기고 `docs/decisions.md`에 기록한다.
