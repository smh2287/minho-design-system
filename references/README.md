# 자료의 용도

자료를 **프로젝트 레퍼런스**(이 시스템의 인상·형태를 검토하는 근거)와 **학습자료**(원리를 배우는 곳)로 나눈다.
같은 출처도 용도가 다르면 따로 적는다. 외부 사이트 이미지·개인 Figma·폰트 원본은 이 저장소에 싣지 않는다.
캡처 원본은 비공개 검토 폴더에만 있다.

## 프로젝트 레퍼런스 — 대상: 이 디자인 시스템

| 자료 | 참고할 부분 | 2026-11-16 Fable의 열람 범위 |
| --- | --- | --- |
| 민호 포트폴리오 (PDF·웹) | 제목 방식(넓은 대문자, 굵기 분절, 민트), 레이블·캡션 위계, 민트의 쓰임, 전시/표 두 밀도 | PDF 5쪽과 웹 화면 2장(넓은·좁은)을 캡처로 직접 봄. 라이브 조작 없음 |
| Dorian Lods <https://dorianlods.com> | 전시 제목 한 곳에 건 굴절 효과의 강도와 자리 | 수상 기록 페이지 영상의 한 장면 캡처 1장. 사이트 본체·hover 미확인 |
| Maxime Heckel <https://maximeheckel.com/> | 작품과 구현 설명의 분리 | 이전 조사 기록의 글만 읽음. 화면 직접 열람 없음 |

기존 프로젝트의 모든 결정을 일반 규칙으로 확대하지 않는다. 시스템 전체의 외형 복제 대상이 아니다.

## 학습자료 — 외형·수치 채택 아님

| 자료 | 배운 원리 | 2026-11-16 Fable의 열람 범위 |
| --- | --- | --- |
| Geist <https://vercel.com/geist> | 색·표면을 역할과 상태로 나누어 적는 형식, 화면 크기별 상세 표시 구분 | Materials 문서 화면 캡처 1장 + 조사 기록 |
| Porsche Design System <https://designsystem.porsche.com> | 토큰 원본 하나를 여러 도구가 소비, 토큰·부품·패턴 분리 | Tokens 소개 화면 캡처 1장 + 조사 기록 |
| IBM 2x Grid <https://www.ibm.com/design/language/2x-grid/> | 실제 영역의 균등 분할, 한 단위의 배수 간격 | 조사 기록만 |
| Audi <https://styleguide.audi.com/> | 고정 요소와 상황별 변형의 구분 | 조사 기록만 |
| Carbon motion | 일을 돕는 움직임과 표현하는 움직임의 구분 | 조사 기록만 |
| Prism | 광학 원리 학습. 일반 웹 디자인 시스템의 필수 재질이 아님 | 이번에 열람하지 않음 |

‘조사 기록’은 2026-11-15에 다른 작업자가 실제 페이지를 읽고 남긴 사실 기록이다. 기록을 읽은 것과 페이지를 직접 본 것을 구분한다.
캡처는 정지 화면이므로 움직임·조작·현재 상태의 근거가 아니다.

## 제외

- Upstash: 민호가 명시적으로 거절(값싼 인상). 미감·구성 채택 근거에서 제외. 이전 조사 문서의 관찰은 이력일 뿐이다.
