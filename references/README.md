# 자료의 용도

## 미감 원천 / 프로젝트 레퍼런스

- 민호 본인 포트폴리오·Figma: 이 독립 웹 디자인 시스템의 글자·정렬·인상 검토 근거. 기존 프로젝트의 모든 결정을 일반 규칙으로 확대하지 않음.
- Dorian Lods / Maxime Heckel: 광학 표현과 구현의 참고. 시스템 전체의 외형 복제 대상 아님.
- Upstash: 사용자 비선호. 미감 채택 근거에서 제외.

## 학습자료

- IBM / Porsche / Geist / Carbon 조사: 관계 단위, 토큰·부품·패턴 분리, 역할·상태, 움직임 목적을 학습. 그 사이트의 외형 채택 승인이 아님.
- Prism: 광학 원리 학습. 일반 웹페이지 디자인 시스템의 필수 재질이 아님.

상세 기존 조사본은 별도 프로젝트 기록에 보존되어 있다. 이 목록은 원문 재검증이나 신규 조사 완료를 의미하지 않는다.
새 자료는 URL / 대상 프로젝트 / 참고할 부분 / 직접 관찰 여부 / 권리·원본 위치를 함께 기록한다.
외부 사이트 이미지·개인 Figma·폰트 원본은 무단으로 이 저장소에 복제하지 않는다.
