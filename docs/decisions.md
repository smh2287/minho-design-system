# 결정 기록

## 2026-11-15

### 사용자 요청·진행 승인

- 시스템의 중심은 웹페이지 설계 논리. 단순 재질·효과 이미지 모음이 아님.
- GitHub 비공개 저장소를 개발 기준으로 구성. PC는 작업 사본, NAS는 대형 자산·백업 역할.
- Fable이 직접 만든 초안을 보존. 부모가 재해석한 AI 시안과 구별.
- 기존 Figma 서체 Miedinger·Montserrat를 참고 후보로 사용.
- Upstash는 선호 레퍼런스에서 제외.

### 아직 승인되지 않은 제안

- ‘모서리’라는 이름, 고정 모서리 탐색, 민트, 모따기, 검정 중심 팔레트.
- Fable 초안의 현재 숫자·글자 굵기·행 확대를 보편 규칙으로 채택하는 것.
- 프레임워크·패키지 배포·호스팅 사업자·NAS 백업 구성.

### 출처·저자

`lab/fable-v3/index.html`과 README는 기존 Fable 직접 작성 및 후속 버그 수정본을 바이트 그대로 가져왔다.
이번 저장소 구조·문서는 Shimmy가 작성했다. 초안의 색/표면은 CSS이며 생성 이미지가 들어 있지 않다.
이전 부모 제작 AI 비교 이미지 세 장은 이번 코드 원본에 포함하지 않았다.
