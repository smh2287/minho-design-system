### 이번에 만든 것 — 전부 실험 상태, 승인 아님

- 문서 사이트 v0: 시작 / 기초 / 부품 / 패턴 / 실험 / 결정. 작성: Fable.
- `tokens/provisional.css`: 무채색 색 역할 8, 글자 역할 5, 간격 8단계, 선·반경·움직임. 강조색 역할은 비워 둠.
- 사이트의 무채색·시스템 서체·직각·위쪽 탐색은 ‘아직 정하지 않음’의 표시이며 선택된 방향이 아니다.
- 선택 행 + 상세 패널(넓은 화면은 옆, 좁은 화면은 아래 대화상자), 상태 표지(실험·검토·기본), 단추, 정의 행.

### 열려 있는 질문 (사이트 `/decisions/`)

1. 제목의 정체성은 서체의 폭에 있는가, 굵기 분절·정렬 규칙에 있는가. — **먼저 권하는 질문**
2. 강조색(민트 후보)은 서명인가, 조작 표시인가.
3. 전시의 여백과 작업의 밀도 사이에서 무엇이 고정인가.
4. 날카로움은 모서리 형태에 있는가, 글자·정렬에 있는가.
5. 효과가 꺼진 화면도 같은 시스템으로 읽혀야 하는가.

답이 나오면 해당 항목의 표지를 검토 또는 기본으로 바꾸고 이 파일에 날짜와 함께 적는다. 사이트의 메모는 브라우저에만 저장되므로 결정의 근거가 되지 않는다. 민호가 직접 전달한 내용만 기록한다.
