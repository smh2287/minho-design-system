실험

실험안은 고치지 않고 옆에 새로 만든다

여기 있는 것은 기본 양식이 아니다. 비교할 수 있도록 원본을 그대로 두고, 고칠 때는 새 폴더에 복사해서 만든다.

목록

  • 모서리 _초안 v3Fable이 직접 만든 첫 시각 초안. 작업·전시·견본 세 화면, 모서리에 고정한 탐색, 민트·유리·모따기를 끄고 켜는 조작이 있다. 저장·삭제는 페이지 메모리 안의 시연이다. 한 글자도 바꾸지 않고 보존한다.보존
  • 광학 세기 비교같은 화면에 프리즘 하나의 재질만 세 단계로 바꾼다: 기본 무채색 · 은은한 굴절 · 강한 굴절. 글자·배치·조작은 셋이 같다. 굴절과 색 분산은 파장별로 계산하지만 물리 시뮬레이션은 아니며, 화면에 계산과 근사를 구분해 적었다.실험
  • 문서 사이트 v0지금 보고 있는 이 사이트. 무채색·시스템 서체·직각으로 ‘아직 정하지 않음’을 표시한 잠정 양식.실험

초안 v3 바로 가기: 전시 화면 · 견본 화면 · 항목을 연 상태 · 메뉴를 연 상태. 초안에는 이 사이트로 돌아오는 링크가 없다. 브라우저의 뒤로 가기를 쓴다.

광학 세기 비교 바로 가기: A 기본 · B 은은한 굴절 · C 강한 굴절 · 셋 나란히.

두 실험이 서로 다르게 답한 것

  • 탐색v3: 화면 모서리에 고정 · v0: 위쪽 한 줄비교 조건
  • 강조색v3: 민트(끌 수 있음) · v0: 없음질문 2
  • 모서리v3: 모따기 · v0: CSS 기본 직각질문 4
  • 표면v3: 어두운 바탕과 유리(끌 수 있음) · v0: 불투명, 밝은·어두운 화면 모두질문 5

새 실험을 올릴 때

  • lab/이름/ 폴더를 새로 만든다. 기존 폴더는 덮어쓰지 않는다.
  • 무엇을 비교하려는 실험인지 첫 줄에 적는다.
  • 실제로 저장되지 않는 조작은 시연이라고 화면에 밝힌다.
  • 민호가 고른 방향만 기초·부품으로 옮기고, 그때 표지를 검토 또는 기본으로 바꾼다.

이 사이트의 모든 양식은 잠정이며 권위 있는 규격이 아니다. 원본: 저장소 · 토큰: tokens/provisional.css · 외부 글꼴·추적·외부 요청 없음.
