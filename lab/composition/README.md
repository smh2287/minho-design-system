# 구성 두 안 비교

같은 화면을 제목 서체와 배치만 바꿔 두 안으로 놓아 보는 실험. 상태: **실험 · 승인 아님**. 작성: Fable (2026-11-19).

두 안 모두 실험안이다. 민호가 고르기 전에는 어느 쪽도 기초·부품으로 옮기지 않는다.
아래의 취향은 민호 개인의 선호를 따른 것이며 보편적인 디자인 원칙이 아니다.

- **A 여백 포스터**: 제목은 서체 파일 없이 직선과 45° 모따기만으로 직접 그린 넓은 대문자(SVG). 가는 획 사이에 굵은 ‘OF’. 칸을 나누는 선 없이 제목이 아래쪽에서 폭 전체를 쓰고, 고르는 목록과 재질 수치는 접어서 맨 아래 줄 뒤에 숨긴다.
- **B 괘선 색인판**: 제목은 기기에 있는 획 대비가 큰 세리프(대소문자 혼용, ‘of’만 기울임). 7:5 두 칸을 가는 선으로 나누고, 조작과 수치를 접지 않고 모두 꺼내 놓는다.

부제·본문은 두 안 모두 시스템 고딕이다. 주소 끝에 `#a` `#b` `#all`을 붙이면 그 상태로 열린다.
`#all`은 두 안을 제 폭 그대로 위아래로 놓는다(옆으로 놓으면 둘 다 좁은 화면용 배치로 바뀐다).

## 두 안에서 고정한 것

- 굴절: `lab/optical-compare/`의 C(강한 굴절)와 같은 재질 값과 같은 그리기 코드. SF11 계열 근사, 면 기울기 36°, 간격 2.2. 그리기 코드는 그 페이지에서 복사했고 A·B 재질 분기만 뺐다. 계산과 근사의 구분은 그 페이지의 README와 같다.
- 문구, 조작의 종류, 무채색 바탕, 조명, 그림자, 직각 모서리, 강조색의 쓰임(선택·초점·누르는 순간·펼친 표시).
- 프리즘의 크기는 놓인 자리의 크기에 맞춰 정해지므로 옮겨짐·색 번짐의 픽셀 값은 두 안에서 다르다.

## 알고 있는 한계

- 서체와 배치를 한꺼번에 바꿨다. 교차 조합(A 서체 + B 배치 등)은 없다.
- A안 제목은 아홉 글자(E D G O F L I H T)만 그린 그림이다. 다른 제목·한글 제목에는 쓸 수 없고, 글자처럼 고르거나 복사할 수 없다. 화면 읽기 프로그램용 숨긴 글자를 따로 넣었다.
- B안 제목 서체는 기기마다 다르다. 서체 파일은 싣지 않았다(이 저장소는 서체 파일을 커밋하지 않는다). 페이지가 글자 폭을 재서 지금 잡힌 서체 이름을 추정해 보여 준다.
- `lab/index.html`의 실험 목록에는 아직 이 페이지로 가는 링크가 없다(기존 페이지를 건드리지 않는 조건으로 만들었다).

## 확인한 것 (로컬 미리보기, Linux Chrome 한 종, 배율 1)

- 1440px: `#a` `#b` `#all` 전환, 주소 해시 갱신, 가로 넘침 0, 화면 밖으로 나가는 요소 0.
- 390px: 세 상태 모두 가로 넘침 0, 화면 밖으로 나가는 요소 0(A안의 접힌 칸을 모두 펼친 상태 포함), 높이 44px 미만의 링크·단추·선택 행·접는 줄 0. A안 제목은 세 줄로 접힌다.
- 조작: 아래에 놓을 것 세 가지, 15° 돌리기, 처음 각도로. `#all`에서 한 안의 조작이 다른 안에 함께 적용됨. 처음 각도로 되돌리면 같은 그림으로 돌아옴.
- A안의 접힌 줄을 눌러 펼치면 장면 높이에 맞춰 캔버스가 다시 그려짐.
- 페이지 오류 0. 콘솔에는 로컬 서버에 없는 `favicon.ico` 404만 있었다. 중복 id 0.
- 눈에 보이는 둥근 모서리 없음(보이지 않게 덮어 둔 라디오 입력의 브라우저 기본값만 남아 있다).
- 한 번 그리는 시간: 1440px에서 A 약 12ms, B 약 23ms.

## 확인하지 못한 것

- 실제 휴대폰, Safari·Firefox·Windows 브라우저, 배율 2 이상 화면.
- B안 제목이 다른 기기에서 어떤 서체로 보이는지. 확인한 기기에서는 Noto Serif CJK KR이 잡혔고, 이것은 획 대비가 크지 않은 세리프다. Windows·iOS·Android에서 의도한 인상이 나오는지는 모른다.
- 화면 읽기 프로그램 낭독, 키보드 Tab 순서의 수동 검증.
- 색 정확도, `prefers-reduced-motion`을 켠 실기 확인.
- 배포된 주소에서의 동작. 이 페이지는 로컬에만 커밋했고 push·게시하지 않았다.
