# 광학 세기 비교

같은 화면에 광학 세기만 세 단계로 바꿔 보는 실험. 상태: **실험 · 승인 아님**. 작성: Fable (2026-11-16).

- A 기본: 같은 모양의 불투명한 무채색 판. 굴절 없음.
- B 은은한 굴절: 가벼운 플린트 유리(F2 계열 상수), 면 기울기 20°, 간격 1.2.
- C 강한 굴절: 무거운 플린트 유리(SF11 계열 상수), 면 기울기 36°, 간격 2.2.

글자·배치·여백·조작 부품·조명·그림자·프리즘의 크기와 위치는 세 장면이 같다. 한 개의 HTML·CSS·그리기 코드를 쓰고 `OPT` 값만 다르다.
주소 끝에 `#a` `#b` `#c` `#all`을 붙이면 그 상태로 열린다.

## 무엇이 계산이고 무엇이 근사인가

- 계산: 윗면·바닥면 두 경계의 스넬 굴절, 400–700nm 16개 파장별 굴절률(두 항 근사식 `n = A + B/λ²`).
- 근사: 유리 상수(공개된 n_d와 아베수에서 직접 맞춤), 파장 → 화면 색 변환, 표면 반사(슐릭 근사 + 넓은 조명 하나), A의 면 밝기.
- 연출: 그림자, 능선·가장자리 선, 빛줄기의 번짐.
- 생략: 유리 속 반복 반사, 집광 무늬, 편광, 흡수, 원근. 시점은 정면 수직.

물리 광학 시뮬레이션이 아니다. CSS 유리 효과(뒤 흐림·반투명)는 쓰지 않았다.
그림은 Canvas 2D에 한 점씩 계산해 그린다. WebGL은 쓰지 않는다(확인에 쓴 브라우저에 WebGL이 없었고, 한 가지 경로만 두기 위해서다).

## 확인한 것 (로컬 미리보기, Linux Chrome 한 종, 배율 1)

- 1440px: A·B·C 전환과 ‘나란히’. 나란히 놓았을 때 세 장면의 제목 위치·크기와 단추 위치, 장면 높이가 픽셀 단위로 같음.
- 390px: 가로 넘침 0, 높이 44px 미만의 링크·단추·선택 행 0.
- 조작: 아래에 놓을 것 세 가지, 15° 돌리기, 처음 각도로. 나란히 상태에서 한 장면의 조작이 세 장면에 함께 적용됨.
- 주소 해시로 상태 열기, 중복 id 0, 스크립트 문법 검사, 초점 테두리가 강조색으로 보임.
- 한 번 그리는 시간: 넓은 화면에서 약 0.1–0.2초(소프트웨어 렌더링 기기 기준).

## 확인하지 못한 것

- 실제 휴대폰, Safari·Firefox·Windows 브라우저, 배율 2 이상 화면.
- 화면 읽기 프로그램 낭독, 실제 Tab 순서의 수동 검증.
- `prefers-reduced-motion`을 켠 실기 확인(움직이는 그림 자체가 없고, 색 전환 시간만 0으로 바꾼다).
- 색 정확도. 화면·브라우저의 색 관리에 따라 분산 색이 다르게 보일 수 있다.
- 실제 유리 사진이나 측정값과의 대조.
- 제목 서체. 미리보기 기기의 시스템 서체는 일반 기기와 다르다.
