# 모서리 _초안 v3

`index.html` 하나로 열리는 시각 초안입니다. 외부 의존과 네트워크 요청이 없습니다.

- 화면 속 항목, 저장, 삭제, 되돌리기는 모두 **페이지 메모리 안에서만 동작하는 시연**입니다. 실제로 저장되지 않으며 새로 고치면 처음 상태로 돌아갑니다.
- 화면은 셋입니다: 작업(밀집 목록), 전시(조용한 한 항목), 견본(규칙·글자·색·단추·입력·생애). 왼쪽 아래 모서리에서 바꿉니다.
- 주소 끝에 `#stage`, `#spec`, `#open`, `#menu`를 붙이면 해당 상태로 바로 열립니다.
- 오른쪽 위 "표시"에서 유리와 민트를 끌 수 있습니다. 둘 다 꺼도 언어가 남는지 보기 위한 조작입니다.
